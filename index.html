Flash Firmware

Use Chrome or Edge on desktop. Connect the board using USB, then click the button below.

Your browser does not support Web Serial. Please use Chrome or Edge on desktop.

Flashing Steps

  1. Connect the ESP32-S3-CAM board to your PC using a USB cable.
  2. If required, put the board into bootloader/download mode using the BOOT and RESET/EN buttons, depending on your board revision.
  3. Click Connect & Flash ESP32-S3-CAM.
  4. Select the correct serial port when your browser asks for permission.
  5. Wait until the flashing process completes fully.
  6. After flashing is finished, press the RESET button on the hardware.

Setup After Flashing

  1. After pressing reset, wait for the device to boot completely.
  2. The device will enter Wi-Fi configuration mode and speak a prompt.
  3. In configuration mode, the board will create a Wi-Fi access point with a name containing xiaozhi.
  4. Open Wi-Fi settings on your phone or laptop and connect to that xiaozhi access point.
  5. A configuration page should open. If it does not open automatically, open your browser and access the captive portal manually.
  6. Enter your Wi-Fi name and password, then press Save.
  7. After saving, the device will connect to your Wi-Fi and speak the device verification code.

Bind Device on Xiaozhi

Waveshare’s Xiaozhi tutorial says the device provides a 6-digit device verification code after it is online, and that code is used to add the device in the control panel. Xiaozhi AI tutorial

  1. Open https://xiaozhi.me/ and log in to your account.
  2. Enter the verification code spoken by the device.
  3. Add the device in the control panel.
  4. Set the device role.
  5. Enter the device introduction or description.
  6. Click Save.

Final Step

  1. Restart the device after saving the configuration.
  2. Wait for it to boot and connect normally.
  3. Your smart AI companion is now ready to use.
If needed, wake the device again and listen carefully for the spoken verification code. Waveshare notes that the code can be heard again by waking the device if needed.

Troubleshooting

  • If no serial port appears, check the USB cable and any required USB drivers.
  • If flashing fails, disconnect the board, re-enter download mode, and try again.
  • Make sure manifest.json and all required .bin files are present in the same GitHub Pages project.
  • If the configuration page does not open automatically, reconnect to the xiaozhi access point and manually open the captive portal page.
  • If you miss the verification code, wake the device again and listen to the spoken code once more.
For best results, use a desktop browser with Web Serial support such as Chrome or Edge.
